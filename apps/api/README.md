# GymFlow ERP Backend API

Commercial Multi-Tenant SaaS Gym Management Backend built with TypeScript, Express, MongoDB (Mongoose), and Domain-Driven Design (DDD).

- **Architecture:** Clean Architecture + Repository Pattern + RBAC + Multi-Tenant
- **Domains:** 14 Business Domains
- **Modules:** 74 Standardized Submodules
- **Documentation:** Full guides available in `docs/`
